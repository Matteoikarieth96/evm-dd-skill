# Fictional example: Acme Vaults

Everything in this folder is invented: the project, the people, the addresses, the numbers and the sources (all URLs use the reserved `.example` domain). It exists to show the file formats end to end and to act as the regression test for `build.py` and `check.py`.

```bash
EVM_DD_HOME=/tmp/unused python3 scripts/build.py examples/fictional-protocol --pdf
python3 scripts/check.py examples/fictional-protocol
```
